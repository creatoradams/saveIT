# ADR060: bound private endpoint acquisition

`check-compute-endpoints` extends the signed route acquisition with one VPC-filtered `DescribeVpcEndpoints` inventory and one exact-ID `DescribeManagedPrefixLists` read. The fixed regional EC2 transport and pinned SDK sign both calls. The complete sequence is 27 reads, with 175 seconds overall, 165 seconds for acquisition, ten seconds for stdin EOF and five seconds per provider read. Missing signed bindings fail before provider contact. A failed endpoint check prevents the prefix read. The command emits a fixed status and takes no provider effect.

Require exactly the six signed endpoints in the signed VPC and account. Bind each ID to the regional service name, expected endpoint type and available IPv4 state. Each interface endpoint must report the two application subnets, its one dedicated security group, IPv4 private DNS and two unique ENI IDs. The S3 gateway must report only the application route table and no interface attachments. A separate prefix read binds the exact signed prefix ID to the regional S3 name, AWS owner and ARN, IPv4 and the completed state. Extra endpoints, duplicate IDs, unsupported fields, pagination and foreign ownership fail closed. DNS names and reported ENI IDs supply no connection destination or independent attachment evidence.

Hash the original policy JSON recovered from bounded XML. Require the policy version and a nonempty bounded statement array. Reject duplicates, unsupported scalar types, controls, non-ASCII and the three HTML-sensitive characters outside the producer contract. Canonical serialization sorts object keys ordinally and removes insignificant whitespace while preserving decoded strings and array order. Thus formatting and object key reordering are compatible, and any change to array order requires a new approved digest. The signed expected digest never comes from provider readback. The Terraform output supplies six declaration digests only when the relay network and token endpoint are bound. Release reviewers must inspect the declarations before signing. Existing resource policies and legacy network outputs are unchanged.

The [shared synthetic observations](../../infra/terraform/runtime-endpoints/tests/compute-endpoint-observations.json) pair independently frozen hashes with raw endpoint/prefix XML. The bound Terraform mock compares its six declared digests to those hashes, and the .NET and packaged Linux fixtures consume the raw responses. Live compatibility with AWS response fields and policy serialization remains a pre-apply gate. The check establishes neither IAM evaluation, exclusive ENI attachment, Resolver behavior, reachability, drift prevention nor authority to launch or fence tasks. All roots remain unapplied and services stay at zero.
