# ADR045: separate relay endpoint policy admission

Accepted 2026-11-08; extends [ADR034](034-private-runtime-service-endpoints.md), [ADR043](043-isolated-relay-identity.md) and [ADR044](044-pinned-relay-startup-loader.md). This changes unapplied endpoint filters only. It creates no relay security group, route, task, service, IAM grant or secret value. Exact execution status is in [progress](../progress.md).

Add nullable `runtime-endpoints.relay` metadata, populated from the relay-identity roles, configuration, operational_log, image_repository and binding_ready outputs. Null preserves all four original policy JSON byte strings and the existing resource/packet-path/four-client runtime_network contract. Non-null requires canonical same-account/cell/environment task and execution ARNs, exact own log and execution reference, exact whole-secret ARN/lowercase version UUID, and the staged deployment repository ARN/URL with exactly migration/access/relay execution readers. Reject bootstrap or null image bindings. The producer's binding_ready denotes its declared repository contract; it is not verified IAM or launch readiness.

Reuse the existing policy construction with separate execution and configuration-reader maps. Relay execution joins the ECR authentication/exact deployment pull and own-log-stream create/put filters only. Relay task joins the exact whole-secret GetSecretValue/UUID filter only. Four legacy configured execution readers and all five legacy workload scopes remain unchanged. Keep every TLS, principal, action, per-role other-resource and missing/wrong-version explicit deny. Bound configuration principal denial is named ConfiguredReadersOnly to include the task accurately; null retains its original Sid. No KMS, metadata-IP, STS, query, secret write, BatchGet/List/Describe, scheduler, PassRole or publisher action is added. Secrets Manager performs service-side KMS operations under the existing role/key/service/account/context boundaries.

Attach these filters to the same ECR API/DKR, Logs and Secrets Manager endpoints. Preserve the shared regional starport S3 TLS GetObject policy and its presigned-service Principal '*'; it is not a per-repository image-layer filter. Retain the compact ASCII policy size guard below 18,000 characters, within AWS's 20,480 limit. New relay_admission output contains validated public role/resource/version references only and defaults to null. The legacy runtime_network output remains unchanged for existing discovery consumers.

Tests compare the complete 49 bound statements with an independently authored reviewed JSON fixture, exact null policy hashes frozen from commit 8b92135, endpoint attachments/resource counts, crossed roles and narrow missing/wrong/stage-only version predicates. Negative metadata plans reject aliases, selectors, foreign scopes and malformed or unbound producer references. Additional plans consume the actual local bootstrap relay, staged artifact-store, bound relay and endpoint modules under distinct plan-time mocks. These are declared contracts and limited condition checks, not an IAM simulator or managed service evidence.

Endpoint policy admission filters only requests traversing that endpoint. It does not force PrivateLink use, authenticate a container/image, inspect SG attachments/routes or prove IAM/KMS enforcement. AWS policy changes may take minutes; withdrawing this metadata neither immediately revokes access nor recalls private keys already loaded in a process. No apply or credentials are used here. Preserve ADR043's unresolved direct Logs customer CallerAccount pre-apply compatibility gate.

Next give the relay its own referenced network group and private discovery/transport paths, then isolated task/service bindings. Do not borrow the web or deployment group merely because those clients already reach endpoints. Protected population and signing/promotion, public trust/digest binding, authenticated web workload intake, rotation/drain/fencing, ingress/restricted egress and actual managed verification remain unfinished. All 146 enterprise inventory entries remain in scope.
