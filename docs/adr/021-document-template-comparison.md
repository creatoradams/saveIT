# ADR 021: audited document-template revision comparison

Accepted for the local core, 2026-10-31. Extends ADRs 007/017/020 without adding a table, dependency, event, database privilege or mutation endpoint.

`GET /organizations/{organizationId}/document-templates/{templateId}/compare` requires the protected session, live membership and current organization role through the existing transaction-local tenant boundary. Viewer and Editor can read active or archived history. The current head supplies existence and version only. At most two exact immutable snapshots from the scoped template are selected; missing/unreadable source never falls back to head content. Same-version and reverse comparisons are valid. Versions must be positive Int32 values; offsets must address the filtered result (zero remains valid for an empty result).

The response includes exact historical name/title/lifecycle/actor/time summaries, ordinal change flags and paged content lines. Shared LineComparison normalizes line endings for display only, preserves exact storage and explicitly explains line-ending-only changes. Its 250,000-cell ceiling bounds quadratic work; large replacements retain common prefix/suffix and show faithful removed/added middle blocks. Changes-only filtering precedes 200-line pagination. No whole body is embedded in metadata summaries. Inputs are already bounded to 50,000 content characters per immutable snapshot.

Every successful page appends a numeric-version-only `DocumentTemplate.Compared` read audit. Current/source/read-audit/outer-commit failures withhold summaries, lines, counts and cursor. No content, names or recovery reasons enter audit/outbox metadata. Comparison creates no outbox/search event and modifies no template, document, revision, origin or placement. CurrentVersion is informational; it never refreshes publication or creation authority. Existing current-Editor/CSRF/expected-version/active-source locks remain mandatory and stale writes still conflict. ADR 002's in-flight revocation limits remain.

The browser clears results on input/filter changes, each page request, failures and context changes. Owned requests coordinate global busy/cancellation; current-context denial clears the workspace. Results and error panels receive keyboard focus only after unlocking; Close/Escape returns focus to the comparison opener. Literal wrapped text and a focusable scroll region support narrow screens. Comparison is a separate read view, not a historical publication/reapplication flow.

Template restore/reapply, executable variables, bulk/cross-organization generation, rich content/files, operational provider/cloud deployment and independent production assurance remain unfinished. Executed verification belongs in progress and the review report; this ADR alone is not test evidence.
