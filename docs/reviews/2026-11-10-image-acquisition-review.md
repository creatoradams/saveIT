# Image configuration acquisition review

Scope: ADR056's fixed ECR SDK reads, original signed manifest/configuration digest chain, bounded registry bearer parsing and confined Basic GETs, strict inherited image startup policy and shared immutable transport descriptors. No provider write, launch, ownership handoff or fencing is added.

The independent security agent found no actionable hash, destination, authority or cleanup escape in the reviewed source/fixtures. It checked exact repository/account/digest and original UTF8/size correspondence; unknown/duplicate/index/foreign URL/descriptor refusals; Linux/nonroot/entrypoint/command/environment/volume/source checks; distinct ECR SigV4 and registry Basic destinations; freshness/cancellation after each read; and fixed output/owned buffer handling. The review explicitly records that AWS gives no fixed bearer-token maximum: local16KiB token/32KiB envelope caps fail closed and need managed compatibility proof. Managed strings and parsed JSON copies remain sensitive despite owned-buffer clearing.

Tests cover validly approved unsafe configuration/manifest variants for all four images, exact byte/length substitutions, decoded aliases, alternate credential endpoints, failure framing and observed cancellation/real expiry at manifest, authorization and blob stages. Native fixtures copy actual packaged startup configuration into clearly synthetic registry/config digests, re-sign changed task/manifest bindings and verify exact counters. A reachable verified-TLS forbidden destination has its own positive control, so redirect refusal cannot pass merely because a second destination fails TLS/DNS. Proxy/CONNECT/CSM traps, wrong registry hostname, body/EOF deadlines and independently attempted label-checked cleanup remain. Token/private-marker absence is checked through exact output only after child/stdio closure.

Local combined tests pass; expanded34-case native execution remains pending CI because Docker is unavailable locally. The agent executed no tests, containers or AWS calls. No full layer, source-to-binary provenance, signature, scan, license, promotion or managed compatibility claim is inferred. The requested independent efficiency agent remains unavailable after its account usage limit; self-review cannot replace that review. Whole controller, network/private configuration acquisition, explicit ownership transfer, privileged-writer exclusion and process/ENI fencing remain unfinished.
