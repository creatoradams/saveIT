# SaveIT repository guidance

Read `docs/project-brief.md`, `docs/architecture.md`, `docs/progress.md` and relevant ADRs before architectural changes or completion claims. Preserve all enterprise scope in `docs/backlog.md` and `docs/feature-parity.md`; unimplemented capabilities stay visibly unimplemented. Use original SaveIT branding and synthetic data.

Never derive tenant authority from request headers/payloads alone. Preserve live membership/organization checks, transaction-local PostgreSQL context, forced RLS, tenant/organization FKs and the non-owner runtime-role guard. Do not replace real PostgreSQL integration tests with an in-memory provider. Business writes, revisions where applicable, audit and outbox must commit atomically. Development identity stays opt-in and impossible in Production.

Run appropriate .NET tests, `npm run typecheck`, `npm run build`, `npm run check:ignore` and relevant Playwright tests. Regenerate OpenAPI/TypeScript when contracts change. Keep lockfiles, migrations, `.terraform.lock.hcl` when providers exist and sanitized environment examples tracked. Never commit real environment files, state/plans, secrets, test evidence or local DB files.

Document restoration appends a new revision and preserves old snapshots. Keep current Editor/expected-version checks, audited historical comparisons, bounded diff/pages, source/reason provenance constraints and atomic revision/audit/outbox tests. Never place historical content or restore reasons in audit/outbox metadata. Asset/deletion recovery and backup restores remain separate unimplemented work.

Asset relationships never grant access. Preserve both tenant/organization-qualified endpoint FKs, forced RLS, live organization roles, audited bounded reads and lifecycle/duplicate concurrency checks. Removal retains the row and assets/documents; only lifecycle columns are updatable. Search explicitly acknowledges schema-v1 relationship events without indexing them; unsupported events/schemas still dead-letter, and worker column-level core write grants must fail its startup guard.

Organization name history is API SELECT-only. Preserve checked create/rename functions, locked membership-derived actors, fixed origins, exact persisted snapshots and atomic history/current/grant/audit/outbox/queue writes. Backfill only actual current versions, keep fresh Seed attribution and existing-seed idempotence, and restore predecessor functions before dropping history on downgrade. Every bounded history page requires current organization authority and durable read audit. Worker history ownership, column reads and reachable writes remain denied. History never grants rename, restore or permission-administration authority.

Document folders never grant access. Preserve scoped parent/document/folder FKs, forced RLS, column-limited writes, the identical tenant/org advisory lock in API and VOLATILE invoker trigger, READ COMMITTED-only mutations and eight-level/1,000-folder bounds including moved subtree height. Keep raw multirow/lock-wait tests. Placement versions are independent of content versions; filing never rewrites content/history/search, and restoration preserves current placement. Audit reads before serialization and commit mutations/audit/outbox/queue atomically. Worker folder/placement reads and writes remain denied; only known schema-v1 metadata events are acknowledged. Preserve sticky conflict barriers through failed reloads and show fetched current state separately from retained choices. Folder history/lifecycle/ACLs, bulk work and measured root/unfiled scaling remain unfinished.

The search worker is implemented; its tenant-scoped consumer receipts and derived PostgreSQL projection must remain separate from core authority. Search must join current grants/source before fields, previews or pagination and fail closed on source/audit failure. Preserve replay, backoff, dead-letter, rebuild and least-privilege tests. Terraform, OpenSearch, generic external event delivery and connectors remain unimplemented scaffolds/roadmap work. Do not imply enterprise identity, vault/AI, cloud deployment, measured SLOs, compliance or verified vendor parity works until implemented and evidenced. Record limitations and progress accurately.
